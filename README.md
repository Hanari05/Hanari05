## Dự án game nổi bật

### 01 · Game Pixel 2D — Hỗ trợ tập luyện phục hồi chức năng

Prototype nghiên cứu chuyển các động tác tập luyện thành những thử thách
tương tác trong game 2D, với năm màn chơi có cơ chế khác nhau.

**Đóng góp của mình:**

- Phụ trách front-end game.
- Thiết kế và xây dựng năm map.
- Xử lý tích hợp dữ liệu ở phía game.
- Kiểm thử logic và luồng tương tác.

**Công nghệ:** Godot · GDScript · Contract dữ liệu JSON

**Trạng thái:** Đang phát triển. Hiện sử dụng `MockPoseProvider` để mô phỏng
dữ liệu chuyển động; chưa hoàn tất tích hợp camera/MediaPipe thực tế.
Dự án chưa được xác nhận hiệu quả lâm sàng.

[Khám phá dự án →](https://github.com/Hanari05/-NCKH-GamePixel2D_PHCN)

### 02 · Whack-a-Mole — Gameplay mở rộng

Game arcade trên trình duyệt với bàn chơi 15 ô, năm loại chuột,
hệ thống ba mạng và độ khó thay đổi theo điểm số.

**Đóng góp của mình:**

- Đề xuất cải tiến gameplay.
- Tham gia lập trình hệ thống trái tim.
- Tham gia điều chỉnh độ khó.

Các tính năng khác là kết quả phát triển chung của nhóm.

**Công nghệ:** HTML · CSS · JavaScript

[Chơi demo →](https://hanari05.github.io/WhackaMole_LTG/) ·
[Xem mã nguồn →](https://github.com/Hanari05/WhackaMole_LTG)
